「おまかせ」は、そのURLからフィードが見つかれば購読に足し（以後は自動で新着が届く）、 見つからなければその1本だけ取り込みます。 Substack や note は記事URLでもフィードが見つかるので、1本だけ欲しいときは「この記事だけ」を選んでください。
処理は GitHub 側で走るので、反映は次の収集（数分）を待ちます。

貼り付けた本文はこの端末の中だけに保存されます。GitHub にも外部にも送られません。 有料メルマガを公開リポジトリに残さないための作りです。

URL追加をこの端末から使う

「URLから追加」は GitHub のリポジトリにURLを書き込みます。そのためのトークンをこの端末に保存します。 GitHub の Settings → Developer settings → Fine-grained tokens で、 このリポジトリだけを対象に Contents: Read and write を付けたトークンを作ってください。 トークンはこの端末の中だけに置かれます。使わない場合は空のままで構いません（貼り付け追加は不要）。

この端末のデータ

既読・あとで読む・貼り付けた本文は、この端末の中だけにあります。機種変更のときは書き出してください。

保存しているのは、公開フィードに載っている見出しと冒頭までです。有料記事の本文はフィードに入っていないので取得しません。 続きは各媒体で読んでください。
